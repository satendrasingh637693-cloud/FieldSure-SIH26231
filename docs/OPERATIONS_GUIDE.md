# FieldSure Operator Guide

## Sign in

Use your assigned operator ID and password. The prototype seeds demo credentials only for demonstration.

## New test

1. Select the approved kit profile.
2. Capture the test image with the reference card in-frame.
3. Check the capture-quality indicators.
4. Run analysis.
5. Review Positive/Negative/Inconclusive and the evidence indicators.
6. Save the secured record.

## Verify

Select a test ID and run verification. A clean record should show all integrity checks as PASS. A changed image or protected record should cause a verification failure.

## Incident handling

If verification fails, stop relying on the affected record, preserve the original evidence bundle, document the event, and follow the organization's evidence-handling procedure.

## Scientific boundary

The application produces a presumptive field-test interpretation. It does not establish chemical identity and does not replace accredited laboratory confirmation.
